# ADR-004：程序化人体几何与关节融合策略

- 日期：2026-11-21
- 状态：accepted
- 背景：禁止外部模型/贴图，需生成可变形卡通人体并避免大动作裂缝。
- 候选：(A) 球体/圆柱体拼接；(B) 参数化 Loft/Sweep 连续曲面 + 关节过渡几何 + 解析权重；(C) 隐式曲面/体素融合。
- 决定：采用 (B)，canonical bind pose 固定为轻微 A-Pose；躯干用截面 Loft，头用变形椭球，颈/四肢用连续 Sweep + Parallel Transport Frame；肘膝设半径平台与权重渐变；肩髋用重叠/桥接过渡几何。
- 理由：(A) 无法避免裂缝；(C) 移动端成本与复杂度超出 MVP。确定性生成、无外部资产。
- 影响：需权重热力图与关键姿势回归；geometry/weight validator 必须检查退化面/法线/权重和。
- 回滚/替代：若关键姿势仍裂缝，增加局部细分/桥接面并更新本 ADR；不得改回外部模型。
