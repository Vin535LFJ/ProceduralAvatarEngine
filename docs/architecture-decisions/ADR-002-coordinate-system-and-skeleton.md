# ADR-002：坐标系与 Humanoid Skeleton

- 日期：2026-11-21
- 状态：accepted
- 背景：多模块需唯一坐标/矩阵/骨架约定，避免左右手系混用。
- 候选：(A) 右手系 +Y 上 +Z 前 +X 角色左侧，米，列主序矩阵 M*v；(B) SDK 图像坐标直接当世界坐标；(C) 左手系。
- 决定：采用 (A)。内部角度弧度；骨骼 ID 0–21 固定（Root..RToe）；变换链 Parent*Local；时间戳纳秒。
- 理由：与常用图形数学一致；单目 SDK 图像坐标必须显式转换，不得直接驱动米制骨架。
- 影响：所有输入需经坐标 Adapter；单元测试验证矩阵乘法顺序与镜像。
- 回滚/替代：骨骼 ID 变更属 ABI 破坏，需新版本号与全量回归；不得静默重排。
