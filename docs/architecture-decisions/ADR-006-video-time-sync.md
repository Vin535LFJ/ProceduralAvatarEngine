# ADR-006：视频输入与实时姿态时间同步

- 日期：2026-11-21
- 状态：accepted
- 背景：摄像头与本地视频需共用 Motion Runtime；两者时间语义不同。
- 候选：(A) 统一用挂钟时间；(B) 实时模式最新帧覆盖 + 视频模式以 PTS 为唯一基准；(C) 固定推理频率采样。
- 决定：采用 (B)。实时使用容量 1 最新值缓冲；文件视频用 MediaExtractor/MediaCodec 保留 PTS，推理/渲染按 PTS 对齐；暂停/拖动/倍速/重播时清空滤波状态并重置基准。
- 理由：避免队列积压与“动画追赶过去动作”；保证同一 PoseFrame 契约。
- 影响：PoseFrame 必须携带单调纳秒时间戳与源 PTS 元数据；异常时间戳有可测试行为。
- 回滚/替代：若某容器 PTS 不可靠，按设备能力声明不支持该格式，不伪造同步。
