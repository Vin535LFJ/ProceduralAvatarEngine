# 07 — Visual Target Alignment（P1-A 前补充）

## 结论

v1.0 Specification §12.1 的 **Level 1 Stylized Cartoon Human** 是 P1 的必要 baseline，但**不足以单独保证最终产品目标**——“精致、自然、协调、商业游戏角色观感”。

Spec §1.1/§12 明确 P1 不以 Pixar 级、照片级或商业成品角色为验收目标，更高品质留待 P2/P3。因此本次不改变 v1.0 阶段划分，也不把 P1-A Gate 升级成最终产品 Gate；而是在不推翻规范的前提下，补充一套 P1-A 工程视觉目标，用来判断“新几何路线是否具备达到最终目标的基础”。

## 两层目标

| 层级 | 目标 | Gate |
|---|---|---|
| P1-A 工程目标 | 证明 Rig-aware Anatomical Landmarks + Surface Patches + Topology Templates + Variable-profile Sweeps 能生成形态自然、曲面连续、拓扑合理、可继续骨骼变形的卡通人体局部 | 用户 P1-A 视觉确认 |
| 最终产品目标 | 精致、自然、协调的商业游戏角色观感 | P3 及后续产品 Gate；P1-A 不等于完成 |

## P1-A 必须证明的视觉/工程能力

1. 胸腔、腹部、腰部具有连续体积和自然过渡，不是椭球/球体/圆管拼接。
2. 肩胸连接无断层；上臂从肩带自然生长，不是贴合球体或独立圆管。
3. 肘部与前臂在中性姿态和关节动作下都保持合理轮廓。
4. 灰模连续 Lambert 下，正面、侧面、45° 都能读出自然卡通人体体块。
5. 拓扑边界满足 C0 位置连续与 G1 平滑缝法线/切平面连续；硬缝与开放缝显式标记。
6. 法线无翻转，面朝向一致；MeshValidator 通过；生成耗时与真机性能可测。
7. 与 M11/M12 使用相同相机条件做新旧对照；不靠 Toon、材质或三角形数量证明几何质量。
8. 若仍有明显拼装感、圆管感、肩胸断层或不自然过渡，继续迭代 PoC，不进入 P1-B。

## 规范充分性评估

- 充分：Spec §12.1 的“无明显椭球/圆柱/球体拼装感”、§12.2 固定证据协议、§12.4 P1 通过条件、§11 灰模 Lambert 要求，足以约束 P1 几何方向。
- 不足：Level 1 的文字目标不包含“商业游戏角色观感”的成品质量标准，也未量化 patch 边界 C0/G1、动作前后对照或新旧同机位对照；这些由本补充文档和 `docs/foundation/03-geometry-mesh-contract.md`、`05-visual-acceptance-protocol.md` 补足。
- 不修改：不重写 v1.0 规范，不把 P3 的美术质量目标提前压到 P1-A，不用增加模块数量代替几何质量证明。

## 状态

本补充目标随 P1-A 证据一起提交用户视觉验收；P1-A Gate 前状态为 **NOT VERIFIED**。
