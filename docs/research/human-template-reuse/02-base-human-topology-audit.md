## 3. 区域检视

证据图：`evidence/host-proof/images/closeup-*.png`（24 张，线框叠加灰模，480×480）；全身 7 视角 + 右侧视图、线框、法线见 `images/base-*.png`；链 B 的 6 视向灰模与肩、腋近景见 `images-proof-b/`。图像描述模型的逐张描述记录在 R6 §7，这里只列结论。

### 3.1 肩部

- **客观**：肩关节中心位于体表内约 4 cm 以外（关节 40 mm 球内四边形数为 0，因为该球完全在体内）。`upperarm01.L` 只有 2.8 cm 长，真正的上臂是 `upperarm02`。
- **图上观察（模型描述）**：环线从胸廓越过三角肌进入上臂，呈围绕上臂的连续环。
- **适用性判断**：具备 PAE R1/R2 一直做不出来的“胸廓—三角肌—上臂连续环线”。肩外展 70° 时（MakeHuman 权重）翻面 0 个，但单条边最大拉伸 3.19 倍、最小 0.44 倍，位于肩/腋区域——**LBS 在大外展下仍然塌陷，需要 corrective 或 DQS，UNVERIFIED 位置**。

### 3.2 腋窝

- 图上观察：有浅的腋窝凹陷，前后褶与手臂环线汇合，交汇处有少量不规则边/极点。
- 适用性判断：拓扑上干净（利于绑定），解剖上偏“软”。PAE R2 遗留的“腋窝四边界补片未完成”问题在这套拓扑里不存在，因为腋窝本来就是连续四边形流。

### 3.3 髋部 / 腹股沟

- 客观：髋关节中心同样在体内（40 mm 球内 0 个四边形）。髋宽 target 主要移动骨盆区（均值 18.6 mm），大腿区仅 1.3 mm。
- 图上观察：环线从骨盆水平绕过大腿根部，有腹股沟折痕；侧面环线绕过臀部连续。
- 适用性判断：可用。髋屈 60°（MakeHuman 权重）翻面 1 个。

### 3.4 面部

- 客观：眼关节 25 mm 球内 380 个体表顶点、40 mm 内 727 个、同范围四边形 767 个；下颌关节 30 mm 内 55 个顶点。面部是整个网格最密的区域。
- 图上观察：正面可见眼、鼻（含鼻孔环线）、唇、耳；每个眼眶有环线，口部有同心环线；侧面可见耳、眼、鼻、唇、下颌轮廓。
- 适用性判断：具备支持基础表情变形的眼眶/口部环线。**表情/下颌/舌/眼睑的变形质量本轮完全未测**。

### 3.5 手部与足部

- 客观：左手五指各自独立，按最近指骨归属的顶点数为拇指 276、食指 324、中指 321、无名指 317、小指 337；左脚五趾 154 / 175 / 165 / 160 / 193。每根手指 3 节指骨各有独立骨骼。
- 图上观察（手）：五指与拇指分开，每指有环绕指节的环线，拇指根部有独立环簇；掌侧未单独确认。**握拳 50°/关节时手部明显揉皱**（见 R4 §5）。
- 图上观察（足）：从上方看五趾分开、各趾尖端有小环；侧面和 45° 看足趾融合感较强、足弓很浅。
- 适用性判断：手指拓扑足以支持独立骨骼绑定，但**握拳等大幅度手指动作在基础网格 + 纯 LBS 下不成立**；足弓偏平，鞋/赤足细节需要 PAE 自己补形态。两者都不影响“作为可绑定的人体拓扑”。

### 3.6 肘 / 膝 / 颈

- 图上观察：肘、膝有跨越关节的连续环线，密度均匀而非在关节处加密；膝没有额外髌骨几何，读作渐细圆管。
- 屈肘 90°：三种权重翻面 10–15 个；屈膝 70°：5–16 个。属于可接受范围但不是零。

## 4. 已知弱点

1. **细长四边形**：较短对角线剖分后最小角 3.19°、纵横比最大 10.41（链 B 的固定剖分：3.06°、14.26）。三角化方案（对角线选择）会直接影响渲染网格质量，PAE 的 Render Mesh 阶段必须自己决定剖分规则，不能简单按 0-2 对角线切。
2. **价态 3 / 5 的极点**：164 + 156 个。分布位置未统计。
3. **helper 几何是 target 数据的一部分**：肩宽 target 有 1,044 / 5,568 行、身高 target 有 5,770 / 19,150 行落在 helper/joint 顶点上。模板必须携带这些顶点的位置，否则骨架关节不会跟随形态（R6 §4 的失败记录就是这个原因）。
4. **13 个 helper 组**（tights、skirt、hair、双眼、睫毛×4、牙齿×2、舌、生殖器）与 125 个 joint 组混在同一个 OBJ 中。PAE 模板需要明确哪些保留（joint 立方体、眼球、牙齿、舌可作 landmark/附着点），哪些丢弃。
5. **无材质分区、无表面 Landmark**：PAE 需要自己定义皮肤/指甲/眼球/口腔的材质区域和表面解剖标志。不能把 `joint-l-shoulder` 这类关节辅助体当作表面标志。

## 5. 适用性结论

MakeHuman 基础网格是一套**完整、闭合、规则（97.8% 四价）、带 UV、带稳定顶点序号、带关节辅助体**的成人人体四边形拓扑，覆盖 PAE 迄今无法生成的肩、腋、手、足、面部区域，拓扑质量适合“先绑定、后按需局部加密”的用法。它不是为 PAE 的卡通/半写实目标定制的：形态中性、面部和手部偏写实细节、足弓浅、无材质分区、无 PAE 语义区域。这些是 PAE 模板编译器要补的层，而不是拓扑本身的缺陷。

R2（旧路线）的多站点截面、方向性 Shape Basis、PatchAssembler 的校验逻辑和 LOD 思路仍有价值，但应作用在这套拓扑的稳定顶点上，角色表示改为：

```text
Base Human Topology + Shape Target + PAE Shape Basis + HumanRigV2 + Skinning
```

而不是继续从零生成完整人体 Sweep/Bridge。
