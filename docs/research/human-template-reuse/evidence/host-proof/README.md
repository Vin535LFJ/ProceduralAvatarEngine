# Evidence: host-only human-template proof (P1-VR-ARCH-1)

Final run 2026-11-26, produced from the tools committed under `tools/human-template-poc/`
against MakeHuman `a8bc2d54ff0ac92e78ff71431b1023eda42bf482` (CC0 data kept outside git).
Nothing here is Android output: every image is a host software rasterizer.

Integrity: `SHA256SUMS.txt` lists every other file in this folder
(`sha256sum -c SHA256SUMS.txt` from this directory). `tooling-manifest.md` lists the
committed tool sources with their hashes.

## Two independent chains

| | Chain A | Chain B |
|---|---|---|
| Tool | `pae_ht_tests` + `pae_ht_pipeline` (`host/src/`) | `template_proof.cpp` (single file) |
| PAE code reused | ImageWriter, CameraProtocol, ClayRenderer (read-only) | links `build-host/libpae_core.a`: Math, MeshData, MeshTopology, `canonical::detectSelfIntersections` |
| Topology | quads preserved (13,378) | triangulated (26,756) |
| Rig | PAE Rig V2: 102 deform / 20 core, built from `default.mhskel` | source rig loaded as is: 163 bones, world-axis rotations |
| Weights | MakeHuman (facial bones dropped, 175 vertices fall back to `head`) + two PAE generators | MakeHuman (facial bones kept, no fallback needed) |
| Template | `.paht` format 2, write -> read -> write byte-identical (not committed: 4.1 MB, timestamped) | `base.paehuman` (`PAEHUM01`), write only (not committed) |
| Tests | `logs/pae_ht_tests-final.log`: 65 passed, 0 failed | `DIRECTION_CHECK actions=8 failed=0` inside `logs/template-proof.log` |
| Images | `images/` (84) | `images-proof-b/` (17) |

The two chains agree on: 13,380 body vertices, 13,378 quads, 26,756 triangles, 21,334 UVs,
height 1.6659 m, volume 54.9 L, zero boundary / non-manifold / winding conflicts.

## Reproduce

```powershell
# chain A
powershell -File tools/human-template-poc/host/build.ps1
$w = 'build-host/human-template-poc'; $a = '<pinned MakeHuman repo root>'
& "$w/pae_ht_tests.exe" "$a/makehuman/data" $a "$w/out/test-scratch"
& "$w/pae_ht_pipeline.exe" --data "$a/makehuman/data" --repo $a --out "$w/out" --commit a8bc2d54ff0ac92e78ff71431b1023eda42bf482
# chain B (needs the engine host build: cmake -S native -B build-host -DPAE_HOST=ON ...)
powershell -File tools/human-template-poc/host/run_template_proof.ps1 -Assets $a
python tools/human-template-poc/host/render_proof.py "$w/out"
```

## Limits of this evidence

- No human has looked at these images; observations in the reports come from an image
  description model and are marked as such.
- `.paht` and `base.paehuman` hashes change on every run (they embed a UTC timestamp);
  what is verified is the write -> read -> write round trip inside one run.
- Chain B's `ZERO_RESET max_error=0` multiplies the target deltas by 0 and is therefore
  not a test of the real path. The real-path checks are chain A's T06a-T06c.
- Images are recompressed losslessly (pixel hashes are printed in `logs/recompress*.log`).
