## 1. OQ-03 决策草案（肩根接缝 ≤5° 的性质）

### 1.1 问题

现有 Register 记为："≤5° 肩根接缝失败在 PoC-SM 前算阻塞还是可接受风险？"（状态 `BLOCKING`，方案建议：阻塞）。

### 1.2 收敛后的决策文本（建议）

> **决策（建议）：**
>
> 1. **≤5° 是 PoC-SM 的几何验收硬条件。** 该阈值来自 SPEC §13 的**既有合同值**，不是本轮新设的阈值。
> 2. **该条件不阻止 PoC-SM 开始编码。** 它约束的是**验收结果**，不是**开发启动**。
> 3. **测量值 > 5° 阻止 PoC-SM 几何 PASS**，即 `G-P1-GEO` 不得判 PASS。
> 4. **测量值 > 5° 阻止 G2 重开后的完整通过**，即重跑的 G2 只能记为部分通过，不得宣称 G2 完整关闭。
> 5. **测量定义、边界与法线口径必须固定**，并写入实现与报告；口径未固定前，任何角度数值（含本文件引用的 47.66° / 16.13°）都不得作为判定依据。

### 1.3 第 5 条的固定口径（本轮给出具体定义，供负责人批准）

`[VERIFIED]` G2 实测的 47.66° / 16.13° 来自 `LayerAMetrics` 的接缝环二面角统计。报告此前**未把口径写死**，导致"≤5°"缺少可复核的定义。本轮固定如下：

| 项 | 固定口径 | 理由 |
|---|---|---|
| **测量对象** | **canonical mesh（固定拓扑四边模板）的肩根 crop 环**（crop 标签 `shoulder-root`，`ringIndex = rings-1`） | 只测固定拓扑的代表面，才能跨路线比较 |
| **角度定义** | 相邻两个 quad 的**面法线夹角**，取值域 **[0°, 180°]** | 夹角 > 90° 说明存在折叠或翻面，必须暴露而不是折成锐角 |
| **法线朝向** | **外法线**，由面顶点绕序（winding）确定；参与统计前必须验证绕序一致性 | 内法线会让角度全部失真 |
| **边界：纳入的 quad** | 上行顶点落在 crop 环上的**那一圈 quad**（即 `ringIndex - 1` 带）；若存在底盖，其扇形三角也纳入并单独标注 | 明确"哪些面参与"是口径的一部分 |
| **边界：排除** | 与该环**不共享边**的 quad | 避免把躯干中段的曲率混入肩根判定 |
| **统计量** | 环上所有相邻 quad 对夹角的 **max**（硬条件用 max，不用 mean） | 合同值是逐点要求，不是平均要求 |
| **输出** | max、mean、p95、纳入 quad 数、参与角度样本数 | 便于复核 |
| **不适用时** | 若路线无 crop 环 → 记 `NOT APPLICABLE`，**不得**记 PASS | 防止用"没有接缝"绕过检查 |

`[RECOMMENDATION]` 上述口径应写入 SPEC §13 作为该合同值的**测量定义**，并成为 PoC-SM 复测与 G2 重跑的共同口径。

### 1.4 决策的后果

| 后果 | 说明 |
|---|---|
| PoC-SM **可以开始编码** | OQ-03 不再是"启动阻塞"，只是"验收硬条件" |
| PoC-SM **几何验收无法通过**（当前） | G2 实测 R1/R2 47.66°、R3 16.13°，均 > 5° → `G-P1-GEO` = FAIL |
| G2 重开**无法完整通过**（当前） | 需 PoC-SM 达成 ≤5° 后重测 |
| **不是** G2 的 kill 项 | 合同原文即为"PoC-SM 阻塞验收条件"，非"停止一切" |
| G3 **不能**因为该问题被签署 | `G-P1-GEO` 未 PASS 前，G3 无从选择路线 |

### 3.4 DEFER 理由

> G2 证据完整且可复核，但 `G-P1-GEO` 判定所需的**验收目标尚不存在**（DEC-05 未批准），
> 且**形态本身尚未达标**（≤5° 合同失败，三路线皆然）。
> 此时签署 G3 等于在无验收标准的情况下选择路线；
> 此时选择任何路线也都是对同一条形态缺陷的重复确认。
> 因此 `DEFER`，补齐 §2.1 四项后由负责人重新决策。
