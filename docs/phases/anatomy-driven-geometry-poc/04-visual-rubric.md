# Visual Rubric — PoC-A / PoC-SM 灰模评价协议

> DEC-05 落地文件。**AI 只定义"怎么评价"，不定义"什么好看"。**
> 参考图、比例标准数值、通过/否决结论全部由负责人填写并签字。
> 状态：`DRAFT — 等待负责人提供授权参考图与 rubric`

## 0. 硬约束

- 没有负责人认可的目标参考形态，AI 只能做数值对照，**不得宣布视觉合格**（SPEC §13 / DEC-05）。
- 负责人保留独立否决权；AI 不得自标 `VISUALLY ACCEPTED`。
- 本报告中的阈值栏除合同已有值外一律 `TBD`，未批前不得判 PASS。

## 1. 评价对象与协议

| 项 | 固定值 | 来源 |
|---|---|---|
| 坐标 | 米，右手系，+Y Up / +Z Forward / +X Character Left | SPEC §8.1 #7 |
| 相机 | 正交，7 固定视角（见 §2） | `CameraProtocol.h:fixedViews()` |
| 灰模 | 软件 Lambert：0.28 ambient + 0.72·max(0,N·L)，背景 (28,28,31)，480×480 | `ClayRenderer.cpp` |
| 光 | 视图系 (right, up, towards camera) = (0.55, 0.78, 0.45)；所有路线/视角相同 | `clayLightInViewFrame()` |
| 取景 | 同一视角内所有路线共用同一 frame；不同视角可各自取景 | `computeSharedClayFrames()` |
| 裁剪带 | PoC-A torso band：hips.y−0.03 .. chest.y+0.01（按模板 spec 派生） | 探针统一 |
| 材质 | 无贴图 / 无毛发 / 无服装 / 无面部细节 | SPEC §14.1 |

复现命令（从隔离 worktree）：

```bash
cmake --build build-host --parallel 4
./build-host/pae_tests/poc_fair_comparison_probe.exe evidence/g2
# 输出 evidence/g2/clay/index.md 与 63 张 PNG
```

## 3. 逐项评价表（负责人填写）

每一项：**参考图编号**由负责人贴入；**判定**填 `PASS / FAIL / NOT RUN`；**备注**写具体位置与缺陷。
不填参考图即视为该指标 `NOT RUN`，不得默认通过。

### 3.4 一票否决项（P0）

- 任何明显的独立肩球、圆管接缝、mesh append 痕迹 → `REJECTED`，停止。
- 肩根/腋窝出现穿透或自交 → `REJECTED`，停止。
- 中线明显不对称且非参考图本身特征 → `REJECTED`。
