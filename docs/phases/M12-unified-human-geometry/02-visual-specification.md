# M12 — 02 视觉规范（上半身）

目标：High-quality Stylized Cartoon Human Upper Body（精致柔和的商业卡通观感）。

## 明确否定（不得出现）

- 低多边形积木人 / 球体圆柱拼装人 / 机械玩具人
- 只有颜色+描边的基础卡通人
- 过度夸张肌肉 / 写实扫描模型
- 肩部独立球体感 / 圆柱接头感 / 两片网格重叠感

## 分区域形态要求（正面/侧面/45 度均须成立）

| 区域 | 要求 |
|---|---|
| 胸腔 | 上宽下收的自然锥形；前胸弧度与背部平坦不同；左右对称；与肩线融合 |
| 腹部 | 适度体积、自然前凸；腰部收窄但无几何凹陷突变 |
| 背部 | 背面平坦微凹（肩胛区域），与正面深度明显不同 |
| 骨盆过渡 | 自腰部外扩至髋部，向大腿根部平滑过渡（本阶段只做上部过渡） |
| 锁骨 | 锁骨线在肩-胸交界形成微弱脊状起伏（卡通适度） |
| 三角肌 | 肩点处的饱满体积，与胸大肌、斜方肌平滑融合，无球状凸起 |
| 上臂 | 自三角肌向下自然收细 |
| 肘部 | 关节平滑过渡，无折角 |
| 前臂 | 纺锤形态（近肘粗、近腕收细） |
| 颈 | 与胸腔顶部、头部平滑连接（头为占位） |

## Visual Quality Gate（用户验收标准，AI 自评仅提供分析）

- Gate A 连续几何：肩-胸-臂真正融合；正/侧/45 度轮廓协调；无拼装感
- Gate B 表面质量：法线连续、无折角/凸起/裂缝/接缝补丁
- Gate C 真实 Renderer：Android GLES 真机截图、多视角齐全、同参数对比

## 固定证据规范

- 分辨率 1920×1080；相机 8 预设（正/背/左/右/45左/45右/肩特写/躯干特写）
- 姿态：静态 A-Pose（禁用动作自动循环）
- 材质：中性哑光单色（关闭服装/头发/面部细节/描边）
- 渲染模式：Shading / Wireframe / Normals 三种
- 改前改后同参数对比
