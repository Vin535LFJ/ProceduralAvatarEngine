# M12 — 03 几何算法比较

三种方案的**可渲染**上半身样本将在 Android Renderer 中实现并对比（M11 的教训：PoC 必须真实渲染）。

## 方案 A：连续参数化曲面（增强 M11 路线）

- 躯干：样条放掠（截面数 7→12+，每站椭圆 rx/rz/roll 独立），前后不对称用双曲线放掠（前片+背片拼接）近似
- 肩/臂：样条扫掠 + 关节球遮挡
- 已知风险：肩胸融合仍是两片曲面的重叠；锁骨/三角肌形体靠截面放大近似，缺乏真实的解剖形体表达；背部平坦化在椭圆截面上无法表达（椭圆前后对称）
- 优点：拓扑规整、蒙皮友好、顶点少

## 方案 B：统一隐式人体表面（SDF 场合成 → Surface Nets）

- 每个解剖区域 = 一个场函数（各向异性椭球/胶囊/rounded-cone），全体 smooth-min 组合；背部平坦化 = 大半径球体 smooth-subtraction；锁骨 = 细胶囊脊
- 提取：Surface Nets（各向异性网格 89×129×49 ≈ 388k 采样）
- **场函数本身就是语义权重**：每个提取顶点对区域场求值 → 自然归属（ribcage→Chest/Spine，deltoid/arm→Shoulder/UpperArm…）
- 风险：分辨率限制细节（5-9mm）；生成耗时（388k 采样 × ~12 原语）；顶点数可能 15-25k（超 M11 预算但质量优先）
- 优点：**真正单一连续曲面**、天生水密、平滑融合由数学保证、任意参数变化不会产生拓扑破洞

## 方案 C：参数化曲面 + 局部隐式融合

- 躯干 = 参数化放掠，肩部 = 局部 SDF 补丁（M11 PoC 的推广）
- 致命弱点（M11 已实证）：补丁与参数化曲面的**交界**无法真正焊接——两套参数化（截面环 vs Surface Nets 顶点）的边界顶点不共享，必然留下重叠遮挡或裂缝。除非在交界处做复杂的边界顶点对齐——成本高于方案 B 本身。

## 比较（设计预判 + PoC 验证项）

| 指标 | A 参数化 | B 统一 SDF | C 混合 |
|---|---|---|---|
| Silhouette | 截面轮廓好，肩部弱 | 场合成形体最自由 | 肩部好 |
| Joint Integration | 重叠遮挡 | **真融合** | 补丁交界难焊 |
| Surface Connectivity | 部件拼接 | **单一水密曲面** | 补丁+主体两套 |
| Skinning | 好 | 顶点分布均匀、场区域权重 | 混合 |
| 三角形 | ~8k | ~30-40k（可 LOD） | ~15k |
| 生成耗时 | ~40ms | 1-3s（初始化可异步） | ~200ms |

## 设计决定（ADR-009 预定，PoC 后确认）

**方案 B 为主**：M12-A 的核心目标是"连续人体表面"——只有统一场合成能从数学上保证它。方案 A 作为对比 PoC 渲染（现有 M11 上半身即其代表）。三角形超预算由 LOD（分辨率档位）与后续优化解决；1-3 秒初始化符合 §11"初始化阶段允许 SDF 计算"。
