## 0. 结论（负结果，如实报告）

**单纯增加手指环线（保形细分）不能解决握拳失败。** 翻面**率**在细分前后几乎不变（全局 7.89%→7.99%），逐指翻面数随面片数 ~4× 等比放大。根因是屈曲姿态下**指间几何干涉**（穿透），与分辨率无关——加密环线只是让更多面片以相同比率翻面，不能阻止手指互相占据空间。

## 1. 手指拓扑测量（`data/finger-topology.md`）

每指约 280 面 / 3 节指骨，顶点/面 ≈1（闭合管状网格 V≈F）。分辨率中等，并非极端稀疏。

## 2. 方法

保形 4-way 四边形细分（每 quad → 4 quad，共享边中点 + 面中心），全网格统一细分（含手指环线），权重按源顶点加权平均传递 + Top-4 归一化，指身份继承。13,380 顶点 → 53,514；13,378 面 → 53,512。同一 rig（关节不变）蒙皮握拳/指屈。

逐指（fist）：每指细分翻面 ≈ 4× base（finger.02.L 121→487、finger.03.L 126→509、finger.01.L 79→312），L/R 对称。**逐指翻面率不变**（如 finger.02.L base 121/289=0.419，subdiv 487/1156=0.421）。

## 4. 混淆检查（权重纯度）

细分权重纯度 **0.9279**（base Region 权重 ~1.00）——朴素平均在指边界把部分新顶点绑到错误骨（7% 质量）。这是细分翻面略增的一个混淆因素，但**即便扣除它，翻面率仍基本不变**，不改变"细分非解"的结论。真正的细化需**区域约束权重传递**保持纯度。

## 5. 归因与出路

- 自交（指间穿透）随分辨率等比放大（130→260），证明是**几何干涉**而非离散化误差。
- 细分增加的是"可翻面片数量"，不是"抗穿透能力"。
- **真正出路**（需后续授权）：
  1. 碰撞感知姿态 / 姿态限位（限制屈曲角使指间不互穿）；
  2. 局部 corrective / DQS（后续授权）；
  3. **保持指间分离的结构化拓扑**（不是单纯加密，而是改变指间相对位置/体积）；
  4. 区域约束权重传递（修复纯度混淆）。
