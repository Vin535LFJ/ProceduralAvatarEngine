# P1-A — 00 Scope & Assumptions

- 目标：在现有 Android GLES3 真机渲染器中，证明新的程序化几何路线能生成形态自然、曲面连续、拓扑合理、可继续骨骼变形的卡通人体局部。
- 范围：胸腔、腹部、腰部、肩胸连接、上臂、肘部、前臂；不穿衣服的基础人体局部；连续灰模 Lambert 验收；固定相机多视角；新旧 M11/M12 对照；拓扑/法线/耗时/性能证据。
- 非目标：完整人体、头部/面部/头发、服装、材质美化、最终商业观感、P1-B/C/D 内容。
- 明确禁止：球体/椭球/圆柱体拼接；增加三角形数量、Shader 复杂度或 Toon 材质作为几何质量证据；用单一相机截图判断质量。
- 用户 Gate：完成后停止，提交证据等待项目负责人视觉验收；未通过不进入 P1-B。
