# M0 — 01 需求

- 需求 ID：ART-001、COMP-001、TEST-001、TEST-002 及全部 MVP 需求的 ID化（见 `docs/requirements/requirements-baseline.md`）。
- 目标：形成可复现起点；每条 MVP 需求有 ID、P0/P1/P2 和可验证验收条件。
- 输入：三份治理文档、初始目录内容、只读环境探测结果。
- 输出：charter、audit、dependencies、risks、requirements baseline/RTM、project status。
- 验收：仓库现状有事实记录；工具链与未知项标注；需求与验收条件齐备；设备能力仅记录声明值，不把声明当实测。
