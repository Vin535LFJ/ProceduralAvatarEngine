# M8 — 01 需求

- **FUN-IN-002 本地视频输入**（P0）
  - 用户可从设备存储选择一个视频文件（SAF 优先；无 DocumentsUI 设备用应用内浏览器），解码帧送入与摄像头/Synthetic 相同的 `IPoseProvider`/`PoseFrame` 接口。
  - 验收：真机选定视频后解码循环启动，logcat 输出解码帧数、PTS、推理耗时；`hasPerson=false` 时角色保持中性降级。
- **FUN-IN-002-a PTS 同步**（P0）
  - `PoseFrame.timestampNs` = 视频帧 PTS（µs→ns）；播放、姿态、渲染遵循同一视频时间轴；推理慢时按时间轴跳过过期帧，不积压。
  - 验收：logcat 显示 PTS 单调递增且与播放进度一致；跳帧有计数。
- **FUN-IN-002-b 播放控制状态机**（P0）
  - 播放/暂停/恢复、拖动（±10s）、倍速（1x/2x/0.5x）、结束、重新播放。
  - 验收：每项控制在真机执行且行为正确（暂停停帧、拖动跳转后不沿用旧姿态、倍速生效、结束后可重播）。
- **FUN-IN-002-c 滤波重置**（P0）
  - seek/重播/倍速切换时重置 MotionRuntime 滤波与平滑状态，避免旧姿态平滑残留。
  - 验收：宿主单测覆盖 reset 语义；真机拖动后角色无旧姿态"漂移回弹"。
- **FUN-IN-002-d 失败路径**（P1）
  - URI 失效、无解码器、编解码异常、不支持格式：明确日志与用户提示，资源释放，应用不崩溃。
  - 验收：构造失败路径（选非视频文件/无解码器格式）有明确提示。
- **COMP-002 生命周期**（P1）
  - Activity Pause/Resume、Surface 重建不影响视频解码线程的资源正确释放与重启。
  - 验收：真机反复 Home/返回/旋转后视频链路可重新启动。
- **OBS-001 视频统计**（P1）
  - 记录解码帧率、跳帧数、推理耗时、当前 PTS。
  - 验收：logcat 定期输出统计。
