# M10 视觉提升迭代 — 合并记录（需求/设计/拆解/实施/验证）

- 日期：2026-11-21；触发：用户反馈数字人观感差（"太丑"）
- 依据：技术规范 §18.7（链路跑通后提升形态质量）、§12.2 质量档位（Medium 允许轻量轮廓）、§5.4/§8.2（程序化五官/材质允许范围）；约束不变：零外部资产、顶点色/程序化着色、GLES 3.0

## 01 需求

- VIS-001（P0）：消除"方块躯干/疙瘩关节/棱柱四肢"观感——躯干多截面平滑化、四肢锥度优化、关节球overshoot减半
- VIS-002（P0）：卡通脸——眼白+虹膜瞳孔（"墨色"材质分支 materialId 4）、眉毛、嘴、鼻，程序化几何实现
- VIS-003（P0）：卡通描边（inverted hull，蒙皮感知）——轮廓是卡通可读性的最大单项提升
- VIS-004（P1）：发型（刘海带）、手部（拇指）、配色默认值、地面接触阴影
- VIS-005（P1）：细分提升——Medium ≈5–6k 三角形、High ≈9–11k（仍在 §12.1 预算内）

## 02 设计

- 面部：眼白球（mat 3）+ 虹膜/瞳孔合并的扁平墨色球（mat 4，新增固定深色分支）+ 高光小白点（mat 3）+ 眉（mat 1）+ 嘴（mat 4 扁椭球）+ 鼻（mat 0 小椭球）。片元着色器加一行材质分支；皮肤材质顶点色阴影逻辑不变。
- 描边：`kOutlineVertex`（与蒙皮顶点着色器相同的 BoneBlock 蒙皮）→ `pos + normal*uOffset`；`kOutlineFragment` 输出 uColor；绘制用 `glCullFace(GL_FRONT)` 只留背面壳。角色绘制后追加 1 个 draw call。
- 接触阴影：独立微型无蒙皮 program，圆盘网格（自建 MeshData，根骨权重），blend 开、depthMask 关，画在角色之前。
- 细分：radial=12+6*detail，rings=10+6*detail（Low/Med/High ≈ 2.2k/5.5k/9.8k 三角形）。
- 比例默认值：headScale 1.0→1.12、armRadius→0.062、legRadius→0.082、handScale→1.15（卡通头身比）。
