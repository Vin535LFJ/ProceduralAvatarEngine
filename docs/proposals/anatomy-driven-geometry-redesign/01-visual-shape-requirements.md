# 01 — Visual Shape Requirements

## 1. 目标形态定义

目标不是医学解剖复制，也不是肌肉展示模型，而是**商业游戏观感潜力的精致、自然、协调的程序化卡通人体**。形态需要在中性灰模下成立：正面、侧面和 45° 均可读；不是依赖 Toon、描边、材质明暗或外衣遮挡。

“卡通”应通过整体比例、体块节奏、局部夸张和轮廓简化来表达，不等于把人体切分成更光滑的球、胶囊和圆管。

## 2. 全局比例体系

### 2.1 统一坐标和尺度

- 坐标：右手系，`+Y` 向上、`+Z` 朝角色正面、`+X` 朝角色左侧。
- 线性尺寸统一使用米；角度内部使用弧度，文档与视觉参数可用度数展示。
- 角色身高 `H` 是归一化基准。高层比例优先采用无量纲比值；几何生成阶段统一转换成米。
- `BodyJoints` 是骨架关节点语义数据，不能代表所有体表形态控制点。

### 2.2 建议的第一测试体型（PROPOSAL / OPEN）

为避免每轮 PoC 都换一套比例，建议先锁定一个中性、轻度运动型、非极端肌肉化的卡通原型。下表仅为第一轮视觉测试起点，**不是已批准的最终人体尺寸**：

| 参数 | 建议值 | 形态语义 |
|---|---:|---|
| 身高 H | 1.70m | 地面至头顶 |
| 头高 | 0.225m | 约 7.6 头身；头部比例可单独风格化 |
| 肩峰间距 | 0.405m | 肩带外轮廓宽，不等同于胸廓宽 |
| 胸腔最大宽 | 0.335–0.355m | 肋廓左右最大跨度 |
| 胸腔前后深 | 0.205–0.235m | 胸骨前凸与背部体积的组合 |
| 腰部最大宽 | 0.255–0.285m | 下肋弓与髂嵴之间的窄段 |
| 腰部前后深 | 0.155–0.180m | 腹壁与腰背厚度，不是整体缩放 |
| 骨盆最大宽 | 0.325–0.355m | 髂嵴/臀外轮廓最大宽度 |
| 骨盆前后深 | 0.190–0.225m | 骶骨、臀肌和腹股沟体积的整体包络 |
| 上臂长度 | 0.275–0.300m | 肩关节中心至肘关节中心 |
| 前臂长度 | 0.245–0.275m | 肘中心至腕中心 |
| 手长 | 0.090–0.105m | 腕横纹至中指尖的比例基准 |
| 大腿长 | 0.385–0.420m | 髋中心至膝中心 |
| 小腿长 | 0.375–0.415m | 膝中心至踝中心 |
| 站姿 | 对称中立 | 双足稳定，骨盆/胸廓无夸张扭转 |
| A-Pose | 双臂外展约 20–30° | 具体 bind angle 必须以当前 Skeleton 合约为准，不能仅看模型截图命名 |

以上数值形成一套可复现的视觉基准；后续应从高度、头身比、肩髋比例、胸腰比和四肢比例推导局部尺寸，禁止让所有局部宽度独立漂移。

## 3. 区域形态规范

### 3.1 胸腔 / Thorax

胸腔是躯干上段的主承载体块，不是一个轴对齐椭球。要求：

- 正面：左右胸廓体积围绕胸骨中线展开；锁骨下凹与胸大肌上缘形成柔和的平面变化，不形成两颗并列圆球。
- 侧面：胸骨与胸前壁有自然前凸；胸椎/肩胛背部有足够体积但不形成圆柱背壳；胸廓最深处不应与最大宽度处被硬性锁定为同一高度。
- 45°：胸大肌从胸骨向肱骨方向过渡，前肩、侧胸与背部之间没有三块拼接的边界。
- 胸廓下缘应通过肋弓形态接入上腹部，不是简单两椭球 smooth union 后留下的均匀鼓包。
- 后背需表达斜方肌、肩胛骨区域、背阔肌上缘的体积层次，但第一阶段不要刻画细小肌纹。

### 3.2 腹部 / 腰部

- 上腹部受肋弓约束，腹壁从胸骨下端向脐上方逐渐过渡。
- 下腹部与骨盆前侧连续，不得成为向内凹陷后再突然膨出的“沙漏圆柱”。
- 腹部前凸由前后轮廓控制；腰侧收窄必须在 45° 侧腰轮廓中可见，不能只缩小横截面 X 宽度。
- 腰背与侧腹的厚度变化应与胸腔、骨盆体积联动；背部不能因为一个巨大布尔 carve 球而成为平板。
- 腹直肌/腹外斜肌属于低幅度形态特征；视觉目标是体块层次，不是预制六块腹肌浮雕。

### 3.3 骨盆 / 臀部上段

- 髂嵴是骨盆横向外扩的控制轮廓，不等同于球状髋部。
- 前侧要有耻骨区/腹股沟上缘的自然体积过渡；后侧要有骶骨和臀肌包络。
- 腰部最窄处向髂嵴扩张的高度、曲率和深度都需要连续变化。
- 髋臼/大腿根部必须为腿根活动留出结构空间，不能靠将两条大腿管插进骨盆壳里遮挡。

### 3.4 肩带 / 肩部

肩部必须被设计为一个连续肩带区域，至少包含：

- 锁骨从胸骨柄附近向外连接肩峰；
- 肩峰/肩胛冈是肩带骨性支撑轮廓，不是突出的尖角；
- 三角肌前束、外侧束、后束构成肩部圆顶，但其轮廓要有方向性；
- 胸大肌上外侧纤维、斜方肌、肩胛周围体积和上臂肱骨端共同定义肩部体积；
- 腋窝是胸壁、上臂内侧和肩胛/胸背之间的**凹面过渡**。只做多个正体积 smooth union 很容易把腋窝填成一团圆鼓包，需要独立的凹面/接触包络约束；
- 手臂抬起时腋窝不应出现洞、拉丝、塌陷或突然的圆管插入感。

### 3.5 上臂 / 前臂

- 上臂至少有前侧肱二头肌体块、后侧肱三头肌体块、外侧肱肌/三角肌下缘过渡；这些肌群不是简单的同心环截面放大。
- 手臂旋转时，肌群相对骨骼有稳定的前后/内外方向；局部截面 frame 应跟随骨架解剖 frame，不应只由曲线切线任意选定。
- 前臂需要屈肌群与伸肌群分布，肘侧较粗，腕侧逐步收窄；最大宽度、最大深度、前后偏移不必位于同一横截面。
- 正面、侧面、45° 都要能读出肌腹方向和腕部收缩。

### 3.6 肘部

肘是关节，而不是一颗球或扫掠截面的局部鼓包。

- 伸直时：肘尖/鹰嘴形成克制的后侧骨性轮廓；内侧和外侧髁不应变成两个突起球。
- 屈曲时：肘窝内侧压缩、后侧肌腱轮廓收紧；外侧皮肤与软组织拉伸；不能在肘关节中心形成单条硬折痕。
- 肘周围需要独立变形区域，定义 hinge axis、压缩侧、拉伸侧、体积保持和 corrective envelope。
- 前臂旋转会影响前臂肌群截面方向，不能单靠骨段距离权重处理。

## 4. 轮廓与曲面质量原则

1. 大形态正确优先于肌肉细节；全局轮廓不合格时不添加细节。
2. 轮廓从头到脚应具有比例节奏，肩线、胸廓、腰、骨盆、手臂自然收放。
3. 正面、侧面、左右 45° 必须同时成立；不能以正面轮廓很好为由忽略侧深或背部扁平。
4. 曲面过渡应通过共享形态模型实现，而非后期涂抹法线。
5. 不把“更平滑”误解为“更像人体”：Smooth Union 可以消除缝隙，但过大的混合半径会让体块变成均匀肥皂泡。
6. 灰模连续 Lambert 是第一评价模式；线框与法线调试是工程证据，Toon/Outline 只能是后续表现层。

## 5. 统一视觉采集契约

每个 PoC 固定设备、GLES 版本、截图尺寸、相机 FOV、model transform、光照和姿势。最少六主视角（front/back/left/right/45L/45R），再加 shoulder/axilla close-up、torso close-up、elbow close-up。每个视角均提供：

- neutral clay / continuous Lambert；
- wireframe；
- normals；
- neutral bind pose；
- 相关动作 pose 前后对照。

采集图像必须保留原始 PNG，不允许缩放裁剪后作为原证据。每张图附 `branch + commit + modelVersion + preset + debugMode + poseId + device + APK SHA` 元数据。迭代对照必须使用同一个 preset id 和同一相机矩阵。

## 6. 评价表

每个区域 1–5 分，附缺陷位置，不用单一综合分覆盖 P0 缺陷：

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 自然度 | 明显拼装/畸形 | 基本可读但体积关系僵硬 | 可信、协调、风格统一 |
| 轮廓 | 正/侧面至少一面失真 | 两面大致合理、45°有问题 | 三维轮廓均成立 |
| 体积关系 | 球/管堆叠 | 体块有层次但衔接弱 | 解剖区域融为一个整体 |
| 曲面连续 | 缝、折线、凹洞 | 无裂缝但局部硬/鼓包 | 无可见接缝或异常曲率跳变 |
| 肩/关节 | 插入管、硬折痕 | 动作能完成但体积流失 | 形态与动作都自然 |
| 拓扑可读 | 随机三角密度 | 局部可编辑但流向一般 | Edge Flow 明确服务变形 |

视觉 Gate 由项目负责人批准；测试通过、FPS 达标或网格水密都不能自动把分数设为通过。
