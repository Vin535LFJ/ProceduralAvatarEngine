# Project Breakdown Structure

## 五层分解

Project → Phase → Milestone → Work Package → Task。

## Phase 定义（每个）

ID / Name / Objective / Requirements Covered / Baseline / Dependencies / Entry Criteria / Scope / Non-Goals / Work Packages / Deliverables / Acceptance Criteria / Exit Gate / Risks / Stop Conditions。

按技术依赖/可交付能力/风险划分，不按代码目录。
