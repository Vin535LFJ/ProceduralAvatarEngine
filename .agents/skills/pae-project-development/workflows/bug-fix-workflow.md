# Bug Fix Workflow

适用：Bug/质量/变形问题。核心：先复现、建基线、分离变量、最小修复，不凭视觉印象大重构。

1. **Preflight + 授权**：核对 Git/白名单。READ_ONLY 起步。
2. **EL-02 复现 + Before Baseline**：先复现问题，建立 Before 基线（固定网格/姿态/相机/Mask）。读源码与测试，查调用链数据流。
3. **归因分离**：区分现象与根因。对变形问题，分开：坐标系错误 / 权重问题 / Joint Position / LBS 方法限制 / 基础网格几何（见 geometry-and-skinning-principles）。标 HYPOTHESIS。
4. **可执行验证**：对高风险假设设计最小测试复现（如非轴对齐骨骼测试）。**不能仅凭数学审查推测就宣称缺陷，必须测试验证。** 查负结果库是否已失败过。
5. **EL-03/07 规格 + WP**：写可验证修复规格 + WP（白名单/停止条件）。
6. **EL-09 最小修复**：只改一个独立变量。修复后跑指定测试。失败存证据、停依赖任务、不降标准。
7. **EL-10 Before/After 回归**：固定 Mask/相机/口径对照。翻面数报翻面率。区分穿透/折叠/体积损失。负结果保存。
8. **EL-12 Gate + 交付**：Gate 评估 + implementation-report + 更新 STATUS。提交需授权。

例（M2 坐标审计）：复现非轴对齐旋转错误→证实 R·ax 机制→最小修复局部单位轴→22 姿态 Before/After→重新归因（elbow 改善、fist 穿透暴露）→不混为一谈。
