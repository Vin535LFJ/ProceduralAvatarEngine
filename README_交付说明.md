# Procedural Avatar Engine 设计交付包 v1.1

本交付包包含三份相互配套的核心文档：

1. `Procedural_Avatar_Engine_Technical_Spec_v1.0.md`：架构与技术规范，定义技术路线、算法边界和 MVP 技术验收标准。
2. `Procedural_Avatar_Engine_Development_Guidance_Plan_v1.0.md`：开发指导计划，按需求 → 设计 → 实施 → 验证 → 阶段门组织 M0–M9。
3. `AI_Implementation_Prompt_v1.1.md`：AI 工程实施总提示词，要求编码 Agent 遵循前两份文档实际检查仓库、分阶段开发和测试交付。

## 建议使用方式

将三份 Markdown 一起提供给能够读写目标仓库、运行终端命令、执行 Gradle/CMake 构建和测试的编码型 AI Agent。启动后先执行 M0 项目审查，不要直接跳过需求和设计阶段开始大规模编码。

## 文档关系

- 技术规范：定义“做什么、技术上必须如何实现”。
- 开发指导计划：定义“每个阶段先做需求、再做设计、再实施和验收”。
- AI 实施提示词：定义“AI 如何按规范和计划操作仓库并交付可验证结果”。
